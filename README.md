# Sorting Algorithms in C

A simple C project with 5 sorting algorithms and an interactive menu.

**Author:** Shahriar Kabir

## Algorithms

| Algorithm      | Time Complexity  | Space  |
|----------------|-----------------|--------|
| Bubble Sort    | O(n²)           | O(1)   |
| Selection Sort | O(n²)           | O(1)   |
| Insertion Sort | O(n²)           | O(1)   |
| Merge Sort     | O(n log n)      | O(n)   |
| Quick Sort     | O(n log n) avg  | O(log n)|

## Compile & Run



**Windows:**
```bash
gcc -std=c99 -o sorting.exe main.c
sorting.exe
```

## Features

- Interactive menu to choose any algorithm
- Enter your own numbers or use a random array
- Shows before/after array and execution time
- Option to compare all algorithms at once
